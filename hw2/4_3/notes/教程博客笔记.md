# word2vec 教程与博客阅读笔记（4.3 配套材料）

> 阅读时间：2026-10-31。目的：对照"论文 → 代码"链条中，社区教程/博客各补充了哪些理解。论文本身（Mikolov 2013 + 负采样论文 + FastText 论文）已在 4.2 报告第五节对照过，这里不重复。

## 1. Xin Rong, *word2vec Parameter Learning Explained*（arXiv:1411.2738，2014，正刊 NeurIPS 2014 workshop）

这篇是"参数学习推导"的事实标准，被社区大量教程引为基础。与原始论文不同，它把推导**做完整**了。本次阅读记录到的要点：

1. **符号约定**：输入词 `w_I` → 隐藏层 `h`（CBOW 为上下文平均向量 `h = 1/C (v_{w1}+...+v_{wC})`；SG 直接是中心词向量 `v_{wI}`）→ 输出层每个词 `w_j` 的得分 `u_j = v'_{wj}ᵀ h`。
2. **层次 softmax（HS）**：输出层由 |V| 个节点变成二叉树，`p(w|w_I) = ∏ σ(⟦n(w,j+1)=ch(n(w,j))⟧ · v'_{n(w,j)}ᵀ h)`——沿根到叶的路径，每个内部节点做一次 sigmoid 二分类（走左/右子树），更新只涉及路径上的 O(log V) 个向量。每个内部节点有独立的输出向量 `v'_n`。
3. **负采样（NS）**：目标变为
   `E = −log σ(v'_{wO}ᵀ h) − Σ_{j=1..k} log σ(−v'_{wj}ᵀ h)`，
   更新规则统一写成 `v'_{wj}(new) = v'_{wj}(old) − η (σ(v'_{wj}ᵀ h) − t_j) h`，其中正样本 `t_j=1`、负样本 `t_j=0`——这个"统一更新式"是理解两类实现代码（gensim 的 syn1neg、原版 C 的 neu1e）的钥匙。
4. **HS 与 NS 的定位**：HS 是"对 softmax 的近似"（O(log V) 但树结构需要额外存储与游走）；NS 是"把多分类改成二分类"（对每个采样噪声词做 sigmoid），两者都绕开全词表 softmax 的 O(V)。
5. **CBOW vs SG 的更新差异**：CBOW 用窗口内 C 个上下文向量平均后再反向传播（每词每窗口一次更新，低频词信息被平均稀释）；SG 是中心词对每个上下文词逐一更新（一个窗口更新 2w 次），因此 SG 对低频词更友好、训练更慢——这与 4.2 实验里"SG 在小语料上明显优于 CBOW、用时约 3 倍"完全对应。
6. 该文另给出反向传导到输入向量 `v_w` 的更新式（HS 的 EH 传播、NS 直接按 `h` 的加权累加），解释了为什么两个权重矩阵都要更新、为什么最终常用输入矩阵 `v_w` 作为词向量。

（subsampling 的 `P(w_i)=1−sqrt(t/f(w_i))` 出自 Mikolov 2013 原文，推荐 t≈10⁻⁵；本笔记来源的阅读摘录未展开该节，公式与讨论见 4.2 报告 §5.1。）

## 2. Chris McCormick 教程（mccormickml.com，skip-gram 上篇 + 负采样下篇）

社区流传最广的 word2vec 教程之一，工程视角，两篇读完后的笔记：

1. **训练样本构造**：skip-gram 把"一个句子"拆成 (中心词, 上下文词) 对，窗口内每个位置都生成样本；窗口边缘用截断而不是填充（与 pytorch-sgns 的 `<UNK>` 填充实现不同，细节见 4.3 报告）。
2. **两个矩阵**：输入矩阵（V×d，查表得隐层向量）与输出矩阵（d×V，算得分）。**输出矩阵是代价所在**：每步要对 V 个词做 softmax（他举例 V=10,000 已很难训练，真实词表动辄几十万）。
3. **负采样把问题改小**：不再做 V 分类，而是对每个 (中心词, 上下文词) 对回答"这两个词是不是邻居"——正样本 + 随机抽的少量负样本，每步只更新"正样本词 + k 个负样本词"的向量，输出矩阵不再是瓶颈。
4. **负样本数 k 的经验选取**：小数据集 5–20，大数据集 2–5（与论文"小数据集 k=5~20、大数据集 2~5"一致）；gensim 默认 negative=5、原版 C 默认 5，本课程语料 600 万词次属"小数据"档位，k=5 合理。
5. **参数推荐**：维度 100–300（数据集越大越高维）；subsampling 阈值 t 常取 0.001（gensim 默认 sample=1e-3，正对应）；迭代 iter 在数据小时可多几轮。
6. 他特别强调的实操细节：训练前要去低频词（min_count），否则噪声词占满梯度——4.2 的 min_count=20 消融就是验证这一点。

## 3. Jay Alammar, *The Illustrated Word2Vec*（jalammar.github.io）

图解风格，适合建立直觉，笔记如下：

1. **词向量的比喻**：把每个词表示成 d 个数字（如 300 个"性格特质得分"），"语言模型就是在给每个词打分"。向量相似 = 词义相近；可视化后相似词聚在一起。
2. **skip-gram 结构**：输入是词（one-hot）→ 隐层就是该词的 embedding 行（查表，无激活）→ 输出层对词表中每个词打分。训练任务是"给定中心词预测上下文词"。
3. **负采样的直观画面**：输出层从"10000 个神经元的多分类"变成"对每个候选词回答 neighbor / not-neighbor 的二分类"，网络随之变窄——这张图是理解 NS 计算量下降的最佳直觉。
4. **词向量运算**：`king − man + woman ≈ queen` 等线性类比，说明词向量编码了可平移的"语义关系维度"；这也是 4.2 里"中国:北京::美国:?"类比评测的来源。

## 4. 三份资料的互补关系（结论）

- **论文**给出"是什么、为什么"（目标、近似、超参数建议）；
- **Rong 的推导**给出"梯度怎么算"（HS 路径更新式、NS 统一更新式 `t_j` 形式）；
- **McCormick**给出"工程上怎么落地"（两个矩阵哪个贵、k 怎么选、min_count 为什么重要）；
- **Alammar**给出"直觉怎么建立"（打分比喻、neighbor 二分类画面）。

三者合起来正好是"论文 → 代码 → 编程技巧"链条的三层：推导看懂 → 工程取舍看懂 → 直觉可复述。
