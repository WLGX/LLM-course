1. 公式逐项修改：System One 决策模型 vs 课件假设
========================================================================
课件公式的三条隐含假设：
  (a) N_block=12Ld^2：稠密 FFN，每个 token 触碰全部参数；
  (b) 12LDsd：MHA、完整方阵配对（4LBs^2d 前向 × 3）；
  (c) 只覆盖预训练前反向主项（6ND），不含 RL 采样与词表头。
System One 类模型（Jev/StartLux 公开口径）逐条打破：

1.1 输出不再是「下一个 token」：无自回归生成，词表头消失
  经典：词表头参数 V*d、每 token 输出 2*V*d FLOPs（V~10 万，d=4096 -> 参数 4 亿、
        每 token 8.2e8 FLOPs）。
  决策模型：choice/score/noul 三类有界头，输出维度 = 候选数 c 或 1，
        每 token 输出 2*d*(c+1) 量级（c 常为个位数 -> 比词表头小 4 个数量级），
        且 K 个问题共享一次编码（成本摊薄 1/K）。
  => 6ND 中的 N 去掉 V*d 项；新增的输出头项可忽略，但需在账本中显式列明。

1.2 MoE：每个 token 只触碰激活专家 -> 6*N_block*D 改用激活参数
  课件 N_block=12Ld^2 是稠密口径；MoE 下：
    N_total = L*(12d^2 + 2*E*d*d_ff + 路由)      （全部专家，决定显存与下载）
    N_active= L*(12d^2 + 2*k*d*d_ff)              （k 个激活专家，决定每 token 计算）
  StartLux 公开口径 35B-A3B：激活比 = 3/35 ≈ 0.086，参数主项直接降为
    6*N_active*D = 6*N_total*D*(3/35)，约为同参数稠密模型的 1/11.7。

1.3 GQA：K/V 投影与 KV 缓存收缩，但 s^2 配对项不变（课件 GQA 页明文）
  课件 GQA 页：「KV 头数减少到 1/4，不等于整个注意力计算减少到 1/4」；
  「query 的总宽度决定主要配对乘加，KV 头数决定存储宽度及 K、V 投影规模」；
  即使多个 query 头共用同一 KV，各查询不同、分数与权重也不同，仍需要各算一套。
  因此 12LDsd 的配对项原样保留；GQA 改的是另两本账：
    (a) K/V 投影：每层每 token 的 K/V 投影 FLOPs 从 4d^2 变为 4d^2*(n_kv/h)，
        N_block 从 12d^2 变为 12d^2 - 2d^2*(1 - n_kv/h)；n_kv/h=1/8 时约 10.25d^2。
    (b) KV 缓存（存储账，不进 FLOPs 公式）：2*L*B*s*n_kv*hd*b，
        n_kv/h=1/8 时为 MHA 的 1/8（课件 KV 缓存页的算例口径）。

1.4 线性注意力（flash-linear-attention）：s^2 项消失，配对项不再随 s 增长
  线性注意力不物化 s^2 分数矩阵，每 token 每层做两次 d*m 量级的小乘加
  （状态更新 k*v^T 与输出 q*S，m 为状态扩展维）：前向约 4*d*m，
  按课件的「前向×3」口径，前反向合计约 12*L*D*d*m —— 与序列长度 s 无关：
    F_attn(线性) = 12*L*D*d*m      （对照：F_attn(方阵) = 12*L*D*s*d）
  等价地看：方阵项是 12LDsd，线性注意力把它变成 12LDdm，m=d 时等于
  「方阵项固定在 s=d 的值」；s>m 时线性注意力才更省——注意这是方向性的：
  短序列（s<m）时线性注意力反而更贵，不能无条件说线性=便宜。
  同时「分数矩阵」显存从 L*B*h*s^2*b 变为状态量 L*B*h*d*m*b（s=8192、h=24、
  b=2 字节时，单层单份分数矩阵从 3.2GB（不可接受）变为状态量（m=64 时约 4.7MB）。

1.5 双向注意力：去掉因果减半，但「多问题一次前向」重新摊薄
  因果掩码可让配对约减半；StartLux 的 Instant 用双向注意力（完整方阵口径，不减半），
  换取的是同一 state 上 K 个问题并行作答：编码只做一次，K 个问题各自从表示分支读出。
  => 每问题的注意力成本 = 全量项 / K。这是「公式之外」的摊销，必须写进账本。

1.6 训练目标：RLCD 让 RL 采样成本进入公式，但单次前向使 rollouts 极便宜
  课件公式只算预训练前反向。校准决策强化学习（RLCD）需要在线采样：
    每步更新：G 次前向采样 + 1 次前反向训练 = (2G + 6) * N_active * s
  关键差别：决策模型的「采样输出」是几个标量/概率，不是长 CoT 文本 ——
  s 里没有数千 token 的思维链，G 路采样就是 G 次单前向。
  口径说明：(2G+6)*N_active*s 只含参数主项；单次前向的注意力项（方阵 4LBs^2d，
  线性 4LBdm）在 s 远小于 d 时是 2% 量级的小项，本算例未计入（与课件忽略注意力的
  主项口径一致）。
  对推理模型（System Two），同一公式里的 s 要换成 s_in + s_think（数千 token），
  这是 System One 能把 RL 训练做成主训练手段的成本根源。

2. 数值算例（示意配置，数字自洽；非未公开论文的真实逐层参数）
========================================================================
算例 S1（System One，方阵注意力 + GQA + MoE，示意）：
  L=16, d=3072, h=24, n_kv=3(1/8), E=16 专家, k=2 激活, d_ff=3072
  N_total = 1.55B + 4.83B ≈ 6.4B；N_active = 2.15B（激活比 0.34）
  F_param = 6*N_active*D = 6.46e+21
  s=  2048: 方阵配对项 6.04e+20（占参数项 0.094）；线性注意力 9.06e+20（0.140，与 s 无关）
  s=  8192: 方阵配对项 2.42e+21（占参数项 0.374）；线性注意力 9.06e+20（0.140，与 s 无关）
  s= 32768: 方阵配对项 9.66e+21（占参数项 1.497）；线性注意力 9.06e+20（0.140，与 s 无关）
  方向性结论：s=2048（<m=3072）时线性注意力反而更贵（0.140 vs 0.094），
  长状态（s>>m）才显出结构性优势——256K 分块长状态场景正是后者。

算例 S2（训练目标拆分：预训练 vs RLCD 在线采样）：
  G=8 路采样、每状态更新 U=4 次、Q=1000000 状态、典型状态 s=512：
    F_RLCD = Q*U*(2G+6)*N_active*s = 9.69e+19
    占 S1 预训练主项的 1.5% —— 单次前向让在线 RL 可负担。
  对照（同一个公式，s 换成 s + t_think）：System One 的 t_think≈0（输出就是读出几个标量）；
  带 2000 token 思维链的 System Two：
    F_RL_CoT = Q*U*(2G+6)*N_active*(s+2000) = 4.76e+20（4.9 倍）
    倍数 = (s+t_think)/s：状态越短、思维链越长越极端（s=128、t=8000 -> 63.5 倍）。
    这就是「决策模型才敢把 RL 当主训练手段」的成本根源。
  附：AutoThink 式置信度引导的自适应推理 = 每问题额外前向次数变成随机变量，
    公式再乘 (1 + E[额外前向])，属于可控的「思考预算」项，同样需要单独记账。

算例 S3（部署侧，训练预算与部署选择回答不同问题）：
  LLM 推理：每 query ≈ 2*N*(s_in + s_out)，取 N=7B、s_in=2048、s_out=500：
    F_LLM = 3.57e+13
  System One：每问题 ≈ 2*N_active*s_in/K（K 个问题摊薄一次编码），K=10、s=4096：
    F_S1  = 1.76e+12（约为 LLM 的 1/20）——与 Jev 公开的~$0.042/百万输入 token、输出免费的价格结构同向

========================================================================
3. 结论：修改后的公式（System One 决策模型训练账本）
========================================================================
F_train ≈ 6*N_active*D
        + 12*L*D*d*m            （线性注意力，m 为状态扩展维；方阵注意力则为 12*L*D*s*d，
                                GQA 不改变配对项，只把 K/V 投影缩进 N_active）
        + 输出头小项（2*d*(c+1)*K，可忽略但需列明）
        + Q*U*(2G+6)*N_active*s   （RLCD 在线采样，若训练含 RL）
其中 N_active = L*((12 - 2*(1 - n_kv/h))*d^2 + 2*k*d*d_ff)（MoE 激活口径，
K/V 投影已按 n_kv/h 缩小）；双向注意力不减半；KV 缓存 2*L*B*s*n_kv*hd*b 是存储账。
K 个问题共享编码的成本摊薄单独记账。6ND 的「ND 主项结构」不变，变的是每一项的系数与变量。
