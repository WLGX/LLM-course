# 【HW4】在线 DPO 与推理模型的在线强化学习（L3 part2 第 124 张思考题）

> 提交文件夹：hw4。完整答案与实验代码见 GitHub：https://github.com/WLGX/LLM-course（hw4/4_3_在线DPO思考题/）

## 摘要

针对思考题两问：①在线 DPO 不仅可能、文献中已有多个变体（Iterative DPO、Self-Rewarding LMs、SPPO），"在线/离线"的分界是**偏好对是否由当前策略自己生成**，而非损失函数；②DeepSeek-R1 等推理模型回到在线 RL，是因为可验证奖励让探索廉价且安全、离线 DPO 的隐式奖励会过拟合漂移（RM 过优化 scaling law）、**自我修正只能在线学**（SCoRe 定理性论证）、以及 GRPO 用组相对优势去掉了 critic 使大规模在线 RL 可行。另附自写微型实验（三位数加法，SFT / 离线 DPO / 迭代 DPO / GRPO 四路线对比，真实运行）：**GRPO 0.825 > SFT 0.608 > 迭代 DPO 0.114 > 离线 DPO 0.098**，且两种 DPO 的坍缩机制不同（离线=偏好对过拟合+长度漂移；在线=首轮坍缩后采样退化、偏好对逐轮递减）。

## 问题一：能否创造"在线 DPO"

**可以，且已经存在。** 离线 DPO（arXiv:2305.18290）的偏好对一次性从旧策略采样打标；在线 DPO 把"采样"放进训练循环：当前策略为每个 prompt 生成多个候选、用打分器（RM/规则/LLM-as-judge）选优劣、再走 DPO 损失。文献中的形式：

- Iterative DPO（arXiv:2312.16656）：每轮从当前策略采样新偏好对迭代训练；
- Self-Rewarding LMs（arXiv:2401.10020，课程所引 2403.04792 系笔误）：模型自打分自生成偏好对；
- SPPO（arXiv:2405.00675）：自我对弈、胜者作 chosen。

价值：偏好对来自策略当前行为区域，缓解离线数据的分布漂移。代价：每轮重新采样打分，且打分器偏置会被迭代放大。

## 问题二：为什么推理模型又大规模采用在线 RL

1. **可验证任务让探索廉价安全**：数学/代码有客观验证器，在线采样能探索新解题路径，R1-Zero 纯 RL 涌现长链推理与"aha moment"——这种过程级探索只能来自在线交互。
2. **离线 DPO 的隐式奖励过拟合与漂移**：偏好信号被压进 β·log(πθ/πref)，对分布外样本过度自信，与 RM 过优化（arXiv:2210.10760）同源。
3. **自我修正只能在线学**：SCoRe（arXiv:2409.12917）证明离线轨迹里模型没有动机改变首答分布，反思行为必须靠在线奖励区分"首答即对"与"修正后对"。
4. **GRPO 让在线 RL 可负担**：组内相对优势 Âi=(ri−mean)/std 取代价值模型（arXiv:2402.03300），天然适配"一条 prompt 多答案"的可验证奖励。
5. **目标变了**：从"拟合人类偏好"到"训练推理过程能力"，后者本质是与验证器交互的动态过程——正是 RL 的原生设定。

## 自写实验（真实运行，CPU）

三位数加法（81 万对组合，held-out 必须真学进位；两位数加法会被背表、四位数对微型模型过难，两版失败设计见报告 §6），字符级微型 GPT（d=128、3 层、4 头，约 1.5M 参数），四路线共享同一 SFT 起点（500 步、held-out 0.608）与同一参考策略：

| 路线 | 测试准确率 | 平均答案长度 | 训练耗时 |
|---|---|---|---|
| SFT（基线） | 0.608 | 3.58 | 39 s |
| 离线 DPO（600 对 × 400 步） | 0.098 | 4.17 | 55 s |
| 迭代 DPO（在线，3 轮×120 步） | 0.114 | 3.65 | 207 s |
| 在线 GRPO（200 步） | **0.825** | **3.58** | 599 s |

三条观察：① GRPO 相对 SFT +0.217 且长度不变——可验证奖励 + 组优势 + KL 锚定在 held-out 上真学到了进位；② 离线 DPO 损失降到 0.066 但泛化崩塌（0.098）且长度漂移（4.17），是偏好对过拟合 + 长度利用；③ 迭代 DPO 首轮坍缩后，当前策略采到的"一正一错"偏好对逐轮递减（400→201→141），无法自恢复——在线机制把每轮退化反馈进下一轮数据。完整日志/曲线/代码见 GitHub（hw4/4_4_后训练技术演进/exp/）。

## 结论与局限

结论：在线 DPO 可行且文献成熟，但"在线"不自动免疫偏好对过拟合；推理模型选择 GRPO 式在线 RL 的微观原因在本实验中具象化（探索新行为的同时锚定已有能力）。局限：约 1.5M 参数、单任务、单种子，属机制演示；文献中迭代 DPO 在 7B 级模型 + 充足偏好对下有效，本实验的坍缩反映极小规模过拟合，不作规模化外推。
