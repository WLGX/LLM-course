# 【HW4】唐诗宋词英译：简单提示、任务标准与边界示例的比较（提示实验）

> 提交文件夹：hw4。报告全文、评分协议与全部原始输出见 GitHub：https://github.com/WLGX/LLM-course（hw4/4_1_诗词英译提示实验/）

## 摘要

对 16 首唐诗宋词（dev 4 首校准 + test 12 首锁定），比较三个提示版本——A 直接翻译、B 加入任务标准、C 只加入边界示例——同一模型（deepseek-chat）同一采样配置，每组合重复 2 次，盲评打分（评审输入不含版本标识，每判定附译文逐字 evidence）。test 集单元均分 **B 0.980 > A 0.954 > C 0.947**（剔除示例泄漏的 T1 后 B 0.978 > A 0.949 = C 0.949）；B 相对 A 改对 3 个单元、0 新增错误，格式违规 4→1；B/C 输入 token 约为 A 的 2.1/2.0 倍。结论：任务标准以约 2 倍输入成本换得术语与例外类别的稳定改善；边界示例不优于最简提示。

## 引言

课件 L3 part1 第 89 张要求：对同一批语言材料，比较简单提示、任务标准、参考资料（示例）的实际作用，逐项核对期限、否定、例外、术语与格式，报告改对、新增错误与成本，允许最简提示胜出。本实验按"先写评价协议再跑实验"执行：评价协议在运行前定稿（`protocol_评分协议.md`），dev 集校准后协议冻结，test 集只评一次、不做挑选。

## 语料与实验材料

16 首诗词（dev：夜雨寄北、回乡偶书、浣溪沙、虞美人；test：九月九日忆山东兄弟、登鹳雀楼、清明、出塞、秋词、静夜思、雨霖铃、声声慢、水调歌头、满江红、鹊桥仙、丑奴儿），每首标注 3–4 个关键语义单元，类别为时间/否定/例外/术语/关系（共 40 单元，完整标注见 `corpus.json`）。

## 方法与提示条件

三版本共用同一系统消息与输出格式要求（JSON：translation ≤120 词、notes 0–2 条每条 ≤30 词、不含标题）：

- A：一句话直接翻译。
- B：A 的指令 + 五条任务标准（①时间与时序 ②否定与例外 ③术语与文化词音译、保留意象 ④关系保持 ⑤格式行数一致、不增不删）。
- C：A 的指令 + 两个"原文→JSON 译文"边界示例，不陈述任何规则。

## 实验设置与统计方法

- deepseek-chat，生成 temperature=0.7 / 盲评 temperature=0，max_tokens=400；每（诗 × 版本）重复 2 次。
- 盲评：评审输入不含版本标识与模型信息；逐单元判定 完整/部分/缺失/错误（1/0.5/0/0）+ 逐字 evidence + 整体可读性 1–5。
- 格式检查程序化（JSON 合法、行数一致、≤120 词、notes 限制、不含题名）。
- 改对 = 相对 A 单元均值 <0.75 → ≥0.75；新增错误 = 反向；其余 ≥0.25 变化记部分变化。
- 原始请求/响应全存档；重试仅限 HTTP 错误/超时/JSON 解析失败且计入成本。

## 实验结果

**格式合规**：A 20/24、B 23/24、C 22/24，违规全部是"行数不一致"（B 的标准 5 把违规从 4 次降到 1 次）。

**单元均分（test）**：A 0.954、B 0.980、C 0.947；整体可读性 A 4.12、B 4.04、C 3.92。

**逐类核对**：术语 A 0.900 / B 0.975 / C 0.900；例外 A 0.929 / B 0.964 / C 0.893；否定、时间、关系三版本均接近满分（天花板）。

**改对/新增错误（相对 A）**：B 改对 3（登鹳雀楼「千里目」、清明「清明」、声声慢「却是」）、新增错误 0；C 改对 1（同「千里目」）、部分变化 2 处负向（杏花村、茱萸少一人）。

**成本（test 生成阶段）**：A 输入 3578 / 输出 2541 token；B 7682 / 2472；C 7178 / 1909；全程 0 重试。

## 译文案例分析

- 清明「清明」：A/C "the Mourning Day"（部分）→ B "Qingming days"（完整）——术语标准的干净改对。
- 声声慢「却是」：A/C "for they are old acquaintances"（转折丢失）→ B "Yet they are…"——例外标准补回转折。
- 登鹳雀楼「千里目」：A "a thousand miles"（部分）→ B/C "a thousand li"——B 靠规则、C 的改善无法从示例内容解释。
- C 的负向变化：杏花村 "a cot amid apricot flowers"（过度意译）；茱萸 "one face missing from the sight"（逐字搬用示例句式）。

## 讨论

- B 的收益集中在它明示规则的类别（术语/例外），在基线已满分的类别无边际作用。
- C 未产生规则级泛化，出现示例句式搬用与过度意译两种副作用。
- **设计瑕疵披露**：C 的示例 2 原文取自 test 集 T1《九月九日忆山东兄弟》3–4 句，C 在 T1 上实际拥有参考译文（协议第 7 节已追加说明）；剔除 T1 后结论方向不变（B 0.978 > A 0.949 = C 0.949），T1 的 C 成绩不作证据。
- 局限：单模型、每组合 2 次重复、评审与生成同模型（盲评 + 逐字 evidence + 温度 0 缓解）、未做显著性检验。

## 结论

任务标准（B）以约 2.1× 输入 token 换得术语与例外类别的稳定改善与更少格式违规（改对 3、新增错误 0）；边界示例（C）不优于最简提示，可读性还略降。最简提示未胜出，但与 B 差距有限。值得保留：标准 2（否定例外）、标准 3（术语音译）、标准 5（格式行数）；示例驱动方式在本任务上不值得保留。
