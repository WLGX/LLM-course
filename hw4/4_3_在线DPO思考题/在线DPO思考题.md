# 在线 DPO 思考题（L3 part2 第 124 张）

## 题目原文

> 从图中可以看到 DPO 需要事先准备训练集，但无需训练时在线生成答案；那么有无可能创造"在线 DPO"？……既然 DPO 已经可以直接利用偏好数据优化模型，为什么后来的 DeepSeek-R1 等推理模型又大规模采用在线强化学习？

---

## 一、能否创造"在线 DPO"：可以，而且已经存在

**"在线 / 离线"的分界不是损失函数，而是偏好数据从哪里来。**

离线 DPO（Rafailov et al., 2023，arXiv:2305.18290）的偏好对 $(x, y_w, y_l)$ 是一次性从某个（往往是旧版本的）策略采样并打标得到的，训练期间数据分布不再刷新。所谓"在线 DPO"，就是把"采样"这一步放进训练循环：**让当前策略 $\pi_\theta$ 自己为一批 prompt 生成多个候选回答，用某种打分机制（奖励模型、可验证规则、甚至 LLM-as-judge）选出优劣，再用 DPO 损失更新参数**。这正是课件提示的思路——"是否由模型自己生成新回答，是离线 DPO 与在线 DPO 的分界；数学、代码等可验证任务可通过验证结果获得新信号。"

这种形式在文献中已有多个名字：

| 方法 | 论文 | 在线机制 |
|---|---|---|
| Iterative DPO | arXiv:2312.16656 | 每轮从当前策略采样新偏好对再训练，迭代多轮 |
| Self-Rewarding LMs | arXiv:2401.10020 | 模型自己打分 + 自己生成偏好对，反复迭代 |
| SPPO（自我对弈偏好优化） | arXiv:2405.00675 | 每轮两两自我对弈，胜者作为 chosen 更新 |
| WPO（加权偏好优化） | arXiv:2406.11827 | 离策略偏好对按当前策略的似然重新加权 |
| RLOO/GRPO 后接 DPO 损失 | DeepSeek-V3 等 | 采样 → 规则奖励 → 构造对 → DPO/GRPO 混合损失 |

从实现上看，在线 DPO 与 PPO/GRPO 的区别只剩"优势估计"这一步：在线 DPO 把每个 prompt 的多次采样压缩成"一对胜负"，然后走 Bradley-Terry 闭式解；GRPO 则保留组内所有样本、用相对优势 $\hat A_i=(r_i-\bar r)/\sigma_r$ 做策略梯度。两者共享同一套"采样—奖励—更新"闭环，只是把信号压成偏好对还是优势向量的差别。

**在线 DPO 的价值**：偏好对来自当前策略的分布，隐式奖励 $\hat r=\beta\log\frac{\pi_\theta}{\pi_{\rm ref}}$ 拟合的是策略当前行为区域的偏好，而非旧策略区域的偏好，缓解了离线数据的分布漂移。**代价**：每轮都要重新采样、打分，计算量高于一次性离线 DPO；打分器（RM 或规则）本身的偏置会通过迭代被放大。

**本实验的验证**：在三位数加法任务上，我用自写的微型 GPT 对比了四条路线（同一 SFT 起点、同一参考策略）：离线 DPO（偏好对一次性从 π_sft 采样 600 对，训练期间不刷新）与迭代 DPO（每轮从当前策略重新采样偏好对，共 3 轮）——迭代 DPO 即"在线 DPO"的直接实现。实测结果见第三节：两种 DPO 在极小模型上都因偏好对过拟合而坍缩（离线 0.098、迭代 0.114，均低于 SFT 基线的 0.608），而带 KL 锚定的在线 GRPO 提升至 0.825。这说明"在线 DPO"在原理上可行、在文献中成立，但**在线机制本身并不自动免疫偏好对过拟合**——本实验里迭代 DPO 首轮坍缩后，当前策略采样质量恶化、每轮能采到的偏好对从 400 对递减到 141 对，恰好是"在线"机制的可见代价；而 GRPO 之所以被推理模型选中，正是它的组优势 + KL 锚定 + 可验证奖励组合更抗这种坍缩。

## 二、为什么 DeepSeek-R1 等推理模型又回到在线 RL

DPO 的吸引力在于简单稳定（无奖励模型、无采样、无 critic），但 R1（DeepSeek-AI, 2025，arXiv:2501.12948）、Qwen3、Kimi K2.5、GLM-5 等推理模型清一色回到在线 RL（GRPO 或变体），原因可以归纳为五条：

**1. 可验证任务让"探索"变得廉价且安全。**
数学、代码等任务有客观验证器（编译运行、判题、规则检查），奖励无偏且随策略生成即时可得（RLVR）。在线采样让模型不断尝试新的解题路径，错误样本以负优势直接抑制、正确的新路径以正优势强化。R1-Zero 就是纯 RL（无任何 SFT）在数学/代码上涌现出长链推理与"aha moment"（模型中途自发"回头检查"）。这种**过程层面的探索行为只能来自在线交互**——离线数据里不存在模型自己新发明的推理轨迹。

**2. 离线 DPO 的隐式奖励会过拟合与漂移。**
DPO 没有显式奖励模型，偏好信号被压进 $\beta\log(\pi_\theta/\pi_{\rm ref})$。当偏好对来自旧策略、训练步数增多时，隐式奖励对分布外样本过度自信，出现与 RM 过优化同源的现象（Gao et al., 2023，arXiv:2210.10760：RM 优化程度越高，真实分数反而下降）。在线采样不断把"新分布"的样本喂回来，是缓解这一问题的直接手段。

**3. 离线偏好数据不支持"自我修正"这类行为的学习。**
SCoRe（Kumar et al., 2024，arXiv:2409.12917）证明了关键一点：**在离线数据上训练，模型学不会自我修正**——因为离线轨迹里"第一次尝试→修正→成功"是静态记录的，模型只需模仿最终答案，没有动机改变自己首轮生成的分布。只有在线 RL 的奖励能区分"首答即对"与"修正后对"，从而真正训练出反思行为。推理模型的核心能力恰恰是这种多轮自我纠错。

**4. 组相对优势（GRPO）让大模型在线 RL 变得可负担。**
PPO 需要与策略同规模的价值网络（critic），显存与训练开销大。GRPO（Shao et al., 2024，arXiv:2402.03300）对每个 prompt 采样一组 $G$ 个回答、用组内标准化优势 $\hat A_i=\frac{r_i-\bar r}{\sigma_r}$ 取代 critic，省掉了价值模型，且天然适配"一条 prompt 多答案"的可验证奖励场景。这让在 100B+ 模型上做在线 RL 成为工程上可行的选项。

**5. 推理模型的最终目标是"过程能力"，不是"回答偏好"。**
RLHF/DPO 时代的优化目标是让模型输出更符合人类偏好（有用、无害、格式好）；R1 时代的优化目标转向推理过程质量（思考长度、探索广度、正确率、格式遵循），并且训练流程变成**多阶段在线闭环**：冷启动 SFT → 推理 RL（R1-Zero 式）→ 拒绝采样扩充数据 → 再 SFT → 全场景 RL。每一步都用"当前策略采样 → 验证器打分 → 更新"的在线循环推进，离线偏好数据只能作为冷启动或蒸馏来源，无法替代这个闭环。

**一句话总结**：DPO 把"对齐"做成了一道静态拟合题，而推理能力的获得（探索、反思、长链思考）本质上是一个**与环境和验证器交互的动态过程**——这正是强化学习的原生设定。所以不是"DPO 被抛弃"，而是任务性质变了：从"拟合已有偏好"回到"在可验证奖励下探索新行为"。

## 三、小规模验证（自写实现，CPU）

**任务**：三位数加法（81 万对组合，held-out 必须真学进位；两位数加法会被背表、四位数加法对微型模型过难，两版失败设计详见研究报告 §6）。**配置**：字符级微型 GPT（d=128、3 层、4 头，约 1.5M 参数，纯 CPU），四路线共享同一 SFT 起点与参考策略：SFT 基线 / 离线 DPO（偏好对一次性采样 600 对，400 步）/ 迭代 DPO（每轮从当前策略重新采样 400 对，3 轮×120 步）/ 在线 GRPO（组内 4 样本、组相对优势、KL 到 ref，200 步）。

**结果**（贪心解码，held-out 1000 题）：

| 路线 | 准确率 | 平均答案长度 | 训练耗时 |
|---|---|---|---|
| SFT（500 步） | 0.608 | 3.58 | 39 s |
| 离线 DPO | 0.098 | 4.17 | 55 s |
| 迭代 DPO（在线） | 0.114 | 3.65 | 207 s |
| 在线 GRPO | **0.825** | 3.58 | 599 s |

（完整损失曲线与日志：`hw4/4_4_后训练技术演进/exp/results/`，图 `fig.png`。）

**结论**：

1. **在线 GRPO 显著优于 SFT 基线（+0.217），且答案长度不变（3.58）**——可验证奖励 + 组相对优势 + KL 锚定确实把模型从 0.608 推到了 0.825，没有靠输出变长来"刷分"。
2. **两种 DPO 都坍缩了**：离线 DPO 在 600 对偏好对上训练 400 步（约 43 个 epoch），损失一路降到 0.066 但泛化崩塌（0.098），且平均长度漂移到 4.17——偏好对过拟合 + 长度利用的教科书症状。
3. **在线 DPO 机制的真实样貌**：迭代 DPO 第 0 轮后策略已坍缩，当前策略采样质量恶化，能采到的"一正一错"偏好对逐轮递减（400 → 201 → 141 对），无法恢复。这直观展示了"在线"的代价：**在线机制把每一步的错误反馈回下一轮的数据，优势与风险都源自同一件事——模型自己生成训练信号**。
4. 呼应问题二：本实验微观复现了"为什么推理模型回到在线 RL"——不是任何在线 RL 都必然好，而是**GRPO 这一特定组合**（可验证奖励、组内标准化优势、对参考策略的 KL 约束）在探索新行为的同时锚定住了已有能力。

**局限**：模型仅约 1.5M 参数、单一任务、单一随机种子，结论是机制演示而非规模化规律；文献中的迭代 DPO/Self-Rewarding 在 7B 级模型 + 充足偏好对 + β 调优下是有效的，本实验的坍缩主要反映极小模型与有限偏好对下的过拟合。
